# BrainTumorDetector
Brain Tumor Detector (PyTorch)
An end-to-end Computer Vision project that classifies brain MRI scans into four categories: Glioma, Meningioma, Pituitary Tumor, and No Tumor. This project demonstrates how to build and train a custom Convolutional Neural Network (CNN) from scratch using PyTorch.

Key Features
High Accuracy: Reached 90.25% test accuracy within 25 epochs.

Custom CNN: Designed a multi-layer architecture with 3 convolutional blocks, max-pooling, and dropout for regularization.

Optimized Training: Implemented with AdamW optimizer and CrossEntropyLoss.

Visualization: Integrated script to visualize model predictions alongside actual labels.

Tech Stack
Framework: PyTorch

Imaging: Torchvision, PIL, Matplotlib

Data Handling: NumPy
